# El Callejero — Street Food Gourmet Website

> Modern marketing website for a Costa Rican street food brand.

---

## What it does

- Responsive landing page showcasing menu, gallery, and location
- WhatsApp ordering integration
- Optimized for mobile-first traffic (90% of restaurant discovery is mobile)
- Fast load times with Vite + lazy loading

## Tech Stack

- **Frontend:** JavaScript · HTML5 · CSS3
- **Build:** Vite
- **Deployment:** Vercel
- **Integrations:** WhatsApp Business links

## Highlights

- Mobile-first design (most restaurant searches are on phone)
- Loading time < 1.5s on 3G
- Custom animations without third-party libraries
